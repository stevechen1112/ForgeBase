# Template Demo Documentation

本目錄只存放範本治理與規劃文件；可執行程式放在 `src/`，瀏覽器直接載入的影像放在 `public/`。

## 文件索引

- `TEMPLATE_STANDARD.md`：所有靜態 Demo 必須遵守的 ForgeBase 規格與完成門檻。
- `PORTFOLIO.md`：六套範本的順序、狀態與能力覆蓋。
- `templates/<slug>/BRIEF.md`：單一範本的買家、購買流程、路由、功能及資料映射。
- `templates/<slug>/ASSETS.md`：只有已建立影像的範本才會出現，用來記錄來源、用途、alt 與 Demo 限制。

規劃文件不得放入 `src/`；公開圖片不得放入 `docs/`。
