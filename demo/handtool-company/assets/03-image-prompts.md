# Image Prompt Pack

These prompts are written for external image-generation tools or briefing human designers. They are optimized for NorthForge's fictional-but-credible export manufacturer identity.

## 1. Homepage Hero Prompt

Create a realistic industrial B2B website hero image for a Taiwan-based professional hand tool manufacturer. Show a clean, organized tool assembly and inspection environment with torque wrenches, insulated screwdrivers, socket sets, and packaged toolkit cases visible in the foreground. The scene should feel export-ready, professional, and technically disciplined. Lighting should be crisp and neutral, with deep navy and steel-blue color cues, subtle orange accents, no cinematic effects, no workers staring at camera, no exaggerated sparks, no fantasy factory elements. Composition should leave negative space for a website headline on the left.

## 2. About Page Hero Prompt

Create a realistic photograph-style image of a mid-sized Taiwanese hand tool manufacturing facility interior. Show an orderly assembly or inspection area with metal tools, measurement stations, labeled bins, and a visible quality-control workflow. The environment should look clean, efficient, and export-oriented rather than massive or dramatic. Neutral industrial lighting, matte surfaces, believable machinery, no cinematic haze, no fake futuristic elements.

## 3. Torque and Socket Tools Category Prompt

Create a high-quality product-category hero image for professional torque and socket tools. Show a 3/8-inch click torque wrench, ratchet handles, chrome sockets, and bit accessories arranged in a clean industrial composition on a matte gray background. The image should feel premium but practical, suitable for a B2B manufacturer website. Avoid consumer-retail styling, loud reflections, and messy layouts.

## 4. Insulated Electrical Tools Category Prompt

Create a realistic product-category image for insulated electrical hand tools. Show insulated screwdrivers, insulated combination pliers, diagonal cutters, and a compact electrician service kit arranged neatly on a neutral background. The image should communicate safety, reliability, and professional use. Use clean lighting and a restrained industrial color palette. Avoid toy-like colors and cartoonish styling.

## 5. Striking and Workshop Tools Category Prompt

Create a realistic category hero image for workshop striking tools. Show a dead blow hammer, soft-face mallet, engineer's hammer, pry bars, and punch tools arranged in a neat mechanical workshop composition. The visual should feel durable, technical, and professional, not rugged-for-drama. Use industrial realism, controlled lighting, and subtle texture detail.

## 6. Automotive Service Tools Category Prompt

Create a realistic B2B category image for automotive service tools. Show spark plug sockets, oil filter tools, a brake service kit, pullers, and hex/Torx tools arranged like a workshop program offering. Clean composition, practical tool realism, matte workshop surfaces, no consumer garage clutter, no racing aesthetics.

## 7. Toolkits and Storage Category Prompt

Create a realistic image for a custom toolkit and storage-solutions category. Show an EVA foam drawer set, a blow-molded service case, and a portable field maintenance kit in a structured composition. The scene should communicate organization, portability, and private-label readiness. Clean background, restrained industrial styling, no bright retail gimmicks.

## 8. Product Hero Prompt Template

Create a realistic product image for [PRODUCT NAME] with model number [MODEL NUMBER]. Show the product isolated on a clean neutral industrial background, with sharp detail on grip texture, finish, mechanism, and professional build quality. This is for a B2B OEM hand tool manufacturer website, so the tone should be credible, technical, and export-oriented. Avoid flashy retail packaging unless explicitly requested.

## 9. Capability Scene Prompt: Packaging

Create a realistic industrial packaging workstation for a hand tool OEM manufacturer. Show organized labeling materials, barcodes, cartons, molded cases, inserts, and quality-check paperwork in a clean export packaging environment. The image should communicate private-label readiness and document discipline.

## 10. Capability Scene Prompt: Inspection

Create a realistic quality inspection scene for a professional hand tool manufacturer. Show measuring tools, inspection documents, calipers, organized metal parts, and a quality-check bench in a clean industrial setting. The image should feel methodical and believable, not dramatic.

## 11. Certification Badge Prompt

Create a clean flat certification badge graphic for a professional export manufacturer website. Use white background, deep navy text, subtle gray outline, restrained orange accent, and clear structured typography. The result should feel like an industrial quality/compliance badge, not a flashy award emblem.

## 12. PDF Cover Prompt

Create a clean PDF cover visual for a professional hand tool manufacturer's OEM checklist or product line card. The design should use deep navy, steel blue, orange accents, subtle technical grid elements, and one realistic tool or factory detail image. The style should feel export-ready, structured, and practical.
