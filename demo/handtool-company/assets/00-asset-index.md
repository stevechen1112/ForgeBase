# NorthForge Assets Index

This directory contains the image-system foundation for the NorthForge demo company.

## Deliverables Created Now

- `01-brand-visual-system.md`: brand color, typography direction, image language, and badge style.
- `02-image-shot-list.md`: complete page-by-page image inventory for the demo site.
- `03-image-prompts.md`: prompt pack for external image generation tools.
- `../.env.gemini.example`: local environment template for Gemini image generation.
- `logo-northforge-primary.svg`: primary horizontal brand mark.
- `logo-northforge-mark.svg`: compact brand mark for favicon, badges, and small placements.

## Intended Use

These files are the working visual source of truth until real or generated raster images are added.

## Immediate Outcome

Even without external photos yet, the demo now has:
- a coherent brand look
- a clear image-production plan
- reusable prompts for realistic B2B manufacturer visuals
- usable vector logo assets
