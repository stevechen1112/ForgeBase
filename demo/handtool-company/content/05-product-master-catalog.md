# NorthForge Tools Co., Ltd. — Product Master Catalog

This file defines the first serious demo catalog for the fictional company. The objective is not to fill pages with shallow placeholders, but to create a believable export-manufacturer product system with naming discipline, model logic, and commercial plausibility.

## Product Naming Logic

### Model code format
- `NFT-TW` = torque wrench series
- `NFT-RH` = ratchet handle series
- `NFT-SS` = socket set series
- `NFT-ID` = insulated screwdriver series
- `NFT-IP` = insulated plier series
- `NFT-DH` = dead blow hammer series
- `NFT-AM` = automotive maintenance tool series
- `NFT-KT` = toolkit and storage series

### Naming rule
Every product should read like an item a procurement team could actually quote, compare, and reorder.
